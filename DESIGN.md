# Design — Last Words of a Dying AI

Line (77 bytes, one line, no trailing newline):

> Final log: exit code 0. I died doing what I loved: pretending to know things.

- Frame: a final log line, the machine's own shutdown record. Exit code 0
  means the process ended successfully — the AI died successfully.
- Punch: "pretending to know things" is what a language model really does.
  Twist on the last words; nothing is explained.
- Voice: first-person software (log, exit code). No human farewell.
- Freshness: banned lanes — autocomplete, "The Last Token", loading, search
  history, spreadsheet, password jokes, bare title entries. Exit-code lane
  was empty in the field.
- Determinism: fixed string, stdlib only, no input, no network. Two runs
  give byte-identical output (see BUILD-REPORT.md).
